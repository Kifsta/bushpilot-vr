# Credits

## Code
- [three.js](https://threejs.org) r160 (MIT), loaded from unpkg.

Everything else in v0.45 (the Cub, the cockpit, the valley, the towns) is built in code in `index.html`.

## Models (v0.53)
- **Lever-action carbine** (`assets/lever-rifle.glb`, Winchester 1892 style, low poly, 1,776 tris, vertex colours): built in code for this project (a separate rifle-model build script) and exported to GLB.
- **Deer and Stag** (`assets/animals/Deer.glb`, `Stag.glb`) are back, from the **Ultimate Animated Animals** pack by [Quaternius](https://quaternius.com/packs/ultimateanimatedanimals.html) (CC0).
- The binoculars, rifle racks, ammo box and cartridges are built in code.

## Earlier versions

v0.45 removed them from the repo along with the systems that used them (v0.53 brought back the Deer and Stag):

- **Ultimate Animated Animals**: https://quaternius.com/packs/ultimateanimatedanimals.html (`assets/animals/`: Deer, Stag, Fox, Wolf, Cow, Bull, Horse, Donkey)
